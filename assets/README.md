# Procedencia de los assets

`chatgpt-official.png` es una copia sin modificaciones del icono oficial de la aplicación ChatGPT publicado por OpenAI, de 1024 × 1024 píxeles. Se usa en la tarjeta de actividad de Discord para identificar el servicio relacionado; no es la identidad del complemento.

- Fuente: [¿Cómo se ve el ícono oficial de la app de ChatGPT para iOS? — OpenAI Help Center](https://help.openai.com/es-419/articles/7905742-what-does-the-official-chatgpt-ios-app-icon-look-like).
- Archivo original enlazado por ese artículo: [PNG oficial](https://images.ctfassets.net/j22is2dtoxu1/intercom-img-d177d076c9a5453052925143/49d5d812b0a6fcc20a14faa8c629d9fb/icon-ios-1024_401x.png).
- Descargado: 22 de octubre de 2026.
- SHA-256: `E799E2FA0D4149A2EC28FC595C8BFB4990BCBB478649791B42ACFF7CDE6E805E`.

ChatGPT, OpenAI y sus marcas y logotipos pertenecen a OpenAI. Este asset se rige por las [directrices y condiciones de uso de marca de OpenAI](https://openai.com/brand/), no por la licencia MIT del código del complemento. Este proyecto comunitario no está patrocinado ni avalado por OpenAI.

`logo.svg`, `composer-icon.svg`, `icon.svg` y `presence.png` son la identidad propia de Codex Discord Presence. El listado del complemento conserva esos iconos propios. `presence.png` sigue disponible como alternativa para la tarjeta de Discord.
